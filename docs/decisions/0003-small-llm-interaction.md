# 0003. 소형 LLM 기반 사용자 인터랙션 계층

- 상태: 제안
- 날짜: 2026-10-10

## 배경
배치 CLI만으로는 사용자가 "어떤 갭을, 어떤 기법으로, 어느 정도 깊이로" 처리할지 조정하기 어렵다.
중간에 소형 LLM을 두어 대화형으로 조정하고 싶다.

## 결정 (제안)
소형 LLM은 "판단을 대신하지 않는 조정자(router)" 역할로 한정한다.
- 사용자 자연어 → 구조화 명령(JSON)으로 변환 (갭 필터, 기법 선택, 대상 함수 지정, 승인/거절)
- 갭 우선순위 제안·요약, 생성 결과 요약
- 실제 실행은 결정적(deterministic) 파이썬 코드가 수행하고, 무거운 생성은 대형(로컬 또는 유료) 모델이 담당
- 단계 사이에 사람 승인 지점(Human-in-the-loop)을 둔다

## 영향
- 1차 구현은 터미널 대화 루프(REPL)로 시작하고, 필요시 웹 UI로 확장한다.
- 소형 모델 출력은 항상 스키마 검증 후 실행하며, 해석 실패 시 사용자에게 되묻는다.
